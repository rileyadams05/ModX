How publishing works

  • Identify every supported release using WIN/Service or Linux/Service, such as WIN/Steam.
  • Choose who will manage future updates, then select the game executable before uploading the completed .CT cheat table.
  • The executable is checked on your device to identify the game. The file and its local path are not uploaded.
  • The cheat table and its publishing information are uploaded to and stored in the ModX GitHub repository. The Vortex Prime website does not keep a separate copy.
  • Tables maintained by their uploader remain privately managed. Community-maintained tables and their completed README are listed for the community to find, download, and maintain.
  • All uploads must be intended for offline or single-player use and may be removed if reported for unsuitable use.
